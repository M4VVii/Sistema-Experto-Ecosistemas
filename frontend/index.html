Guía Rápida

1

Selecciona el entorno

Abre el menú desplegable y define el tipo de hábitat de tu recinto (Acuario, Terrario Tropical, Terrario Desértico o Paludario mixto). El fondo de la página cambia según el ecosistema.

2

Ajusta la capacidad

Mueve el deslizador según el hábitat: litros para un acuario, área en cm² para un terrario, o ambos valores para un paludario mixto. El sistema calculará si el espacio es suficiente para evitar el hacinamiento.

3

Elige los organismos

Haz clic en las tarjetas de la cuadrícula para seleccionar al menos dos especies. Las tarjetas seleccionadas se iluminarán.

4

Evalúa la convivencia

Presiona "Evaluar". El sistema revisará automáticamente si las especies pueden vivir juntos en paz, comprobando que compartan el mismo clima, tengan espacio suficiente y no corran peligro entre ellos. Los monitores del panel de Resultados muestran el diagnóstico y cada conflicto detectado.
